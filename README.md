# Лендинг по макету «Оно тебе надо»
## Описание проекта

Учебный проект, выполненный по предоставленному макету. Представляет собой одностраничный лендинг с семантической разметкой, корректной структурой и соблюдением требований к оформлению по методологии БЭМ. Проект направлен на отработку базовых навыков HTML и CSS, а также принципов аккуратной, валидной вёрстки.

## Основной функционал
* Семантическая HTML-разметка.
* Полное соответствие макету.
* Статичная страница с корректным позиционированием элементов.
* Реализация сеток с помощью Flexbox.
* Организация CSS-структуры по методологии БЭМ.
* Поддержка корректного отображения в основных браузерах.

## Используемые технологии
* HTML5
* CSS3
* Методология БЭМ (Nested)
* Flexbox
* Работа с макетом в Figma

## Полученные навыки
* Построение семантической структуры страницы.
* Работа с блочно-страничной моделью.
* Верстка по макету с точностью до пикселя.
* Разделение стилей на независимые блоки по БЭМ.
* Настройка файловой структуры проекта.
* Первичная оптимизация CSS-кода.

## Запуск проекта
Проект является статичным. Для запуска достаточно открыть файл `index.html` в браузере.

Альтернативный способ:
1. Клонировать репозиторий:

&nbsp;&nbsp; `git clone https://github.com/Vitaliy-EXP/ono-tebe-nado.git`

2. Открыть файл `index.html` в любом современном браузере.
